# 凯莱-哈密顿定理：内涵与对称性

凯莱-哈密顿定理最表层的表述是"矩阵满足它自己的特征多项式"，即若 $P(\lambda) = \det(\lambda I - A)$，则 $P(A) = O$。

初学者第一次看到这个定理时，几乎都会有一种"这是不是耍了个把戏"的感觉——它太像是把变量 $\lambda$ 硬生生换成矩阵 $A$ 的文字游戏了。这种直觉甚至会让人想直接代入：把 $\lambda = A$ 代进 $\det(\lambda I - A)$，得到 $\det(O) = 0$，然后就此收工。但这一步在数学上是严厉禁止的：$\det(\cdot)$ 算出来的是一个**标量**，而 $P(A)$ 算出来的是一个**矩阵**，两者根本不是同一类东西，这样代入偷换了运算的含义。根本上在于，**数乘和矩阵乘法的规则不同**，$\lambda$ 乘一个矩阵，是把它的每个元素乘以 $\lambda$ ，等价于 $\lambda I$ 左乘这个矩阵；而 $A$ 左乘这个矩阵，用的是矩阵乘法的运算规则，所以不能直接把 $\lambda$ 替换为 $A$ 。正确的特征多项式代换规则诸如 $\lambda^2$ 替换为 $A^2$ ，是把数的自乘替换成矩阵自乘。

那么，在正确的展开后的特征多项式中，为什么把 $\lambda$ 换成 $A$ 之后，式子依然精准地等于零矩阵？答案在于：特征多项式不只是编码了矩阵的"特征值"这几个标量信息，它更封装了矩阵在整个空间上的"算子退化规律"。接下来从三个角度拆解这种"对称性"从何而来。

## 一、代数内涵：有限维空间的"压制"

矩阵 $A$ 作用在一个向量上可以不断迭代：$x, Ax, A^2x, \dots, A^kx$。在 $n$ 维空间里，$A^0, A^1, \dots, A^n$ 这 $n+1$ 个矩阵必然线性相关——因为只看 $A$ 的幂次生成的子空间，维数至多是 $n$，塞进 $n+1$ 个矩阵必然挤出线性相关性。于是一定存在一组不全为零的系数，使得

$$c_nA^n + c_{n-1}A^{n-1} + \dots + c_1A + c_0I = O$$

凯莱-哈密顿定理的深刻之处在于：它不光告诉你"一定存在某个多项式能让 $A$ 归零"，而且**直接把这组系数点名道姓地指出来**——它们恰好就是特征多项式的系数。如果没有后面几节的推导，这一点单独拎出来看会让人觉得非常神奇，像是一种莫名其妙的巧合：为什么偏偏是特征多项式这组特定系数，而不是随便哪组能凑效的系数？

## 二、几何内涵：对角化视角下的"逐一击破"

放到可对角化的矩阵上看，这种"巧合"就会显得极其自然。设 $A$ 可对角化，特征值为 $\lambda_1, \dots, \lambda_n$，特征向量为 $v_1, \dots, v_n$。特征多项式可以拆成一次因子的乘积：

$$P(\lambda) = (\lambda - \lambda_1)(\lambda - \lambda_2)\cdots(\lambda - \lambda_n)$$

把矩阵 $A$ 代入，让 $P(A)$ 作用在任意一个特征向量 $v_i$ 上：

$$P(A)v_i = (A-\lambda_1I)(A-\lambda_2I)\cdots(A-\lambda_iI)\cdots(A-\lambda_nI)v_i$$

这里有个关键的合法性问题：一般矩阵乘法不满足交换律，那能不能随便调换这些因子的顺序？能——因为这些因子全都是**同一个矩阵 $A$ 的多项式**（也就是 $A$ 的不同次幂加减单位矩阵的组合），而 $A$ 的任意两个幂次之间是天然可交换的（$A^iA^j = A^jA^i = A^{i+j}$）。正是这一点允许我们把 $(A - \lambda_iI)$ 挪到最右边，让它第一个作用在 $v_i$ 上：

$$P(A)v_i = [\text{剩下一堆矩阵}]\cdot\underbrace{(A-\lambda_iI)v_i}_{=0} = 0$$

也就是说，$P(A)$ 这个算子，把空间里的**每一个**特征向量都"吞掉"、消灭成了零向量。既然特征向量张成了整个 $n$ 维空间，$P(A)$ 作用在空间任何一个向量上都必然是零向量，所以 $P(A)$ 只能是零矩阵本身。

这也就解答了第一节留下的悬念——为什么系数偏偏是特征多项式的系数：因为特征多项式的每一个一次因子 $(\lambda - \lambda_i)$，对应到算子层面就精确地"瞄准并抹平"一个特征方向。特征多项式的根，在标量层面是"逐一让每个特征值归零"；换成矩阵后，$P(A)$ 就是在几何层面沿着每一个主轴方向依次把空间压塌为零。标量域的"根"与空间维度的"消亡"，说的是同一件事的两种语言，这才是"对称性"真正的来源。

## 三、结构内涵：伴随矩阵给出的一般性证明

上面的推导有个前提——矩阵必须可对角化。但凯莱-哈密顿定理对**任意**方阵都成立，包括那些有重特征值、缺特征向量的"病态"矩阵。要覆盖这种一般情形，需要绕开特征向量，直接从行列式的伴随矩阵（adjugate matrix）公式入手，这也是教材里最常见、最严谨的证明路径。

先回忆一个对任意方阵 $M$ 都成立的恒等式：$M \cdot \mathrm{adj}(M) = \det(M)I$。这个式子的意思是，一个矩阵乘上它自己的伴随矩阵，一定能得到"行列式乘单位矩阵"这样一个规规矩矩的对角形式——这本身是伴随矩阵定义（用代数余子式构造）直接推出的性质，不依赖矩阵是否可对角化。

这个式子有一个特别诱人的形状——它把"行列式"这个标量，包裹在了"矩阵乘矩阵"的外壳里。左边是纯矩阵运算，右边虽然是标量 $\det(M)$，但配上了单位矩阵 $I$，所以两边在"矩阵世界"里是同一类对象，可以做矩阵层面的比较。这正好是开头提到的那个"代入偷换"问题所需要的桥梁：只要把 $M$ 换成含有 $A$ 与 $\lambda$ 的表达式，左边就出现了一个还没被"过早求值"的、含有矩阵 $A$ 的乘积；右边则精确地是 $P(\lambda)I$。式子两边都还没有把 $\lambda$ 消耗掉，$\lambda$ 依然是自由变量，$A$ 依然作为矩阵存在于两边——这就避开了开头那个把 $\lambda=A$ 直接代进 $\det(\lambda I-A)$ 的陷阱。

为了让接下来逐项比对 $\lambda$ 的系数时更加干净利落，与 $P(\lambda)=\lambda^n+a_{n-1}\lambda^{n-1}+\dots+a_0$（首项系数为 1）对应得最清楚，这里直接取 $M=\lambda I-A$（而非 $A-\lambda I$）代入，得到

$$(\lambda I-A)\cdot\mathrm{adj}(\lambda I-A)=\det(\lambda I-A)\,I=P(\lambda)\,I \tag{$\ast$}$$

现在关键的一步是观察 $\mathrm{adj}(\lambda I-A)$ 这个东西的结构：它的每个元素都是 $\lambda I-A$ 的某个 $(n-1)\times(n-1)$ 子行列式（代数余子式）。$\lambda I-A$ 的每个元素都只是 $\lambda$ 的一次多项式（对角元是 $\lambda-a_{ii}$，非对角元是常数 $-a_{ij}$），而任何一个 $(n-1)\times(n-1)$ 子式，是 $n-1$ 个这种一次元素之积的和，所以次数自然不会超过 $n-1$。

这一步的洞察其实很朴素：伴随矩阵的每个格子里装的是一个次数有界的 $\lambda$ 多项式，所以整个矩阵可以按 $\lambda$ 的幂次拆开，系数是矩阵——这一步把"矩阵"和"多项式"这两个原本分属不同代数结构的东西，统一成了同一个对象（矩阵多项式环 $M_n(\mathbb{F})[\lambda]$ 里的元素）。因此可以写成

$$\mathrm{adj}(\lambda I-A)=\sum_{k=0}^{n-1}\lambda^k C_k$$

其中 $C_0,\dots,C_{n-1}$ 都是与 $\lambda$ 无关的具体 $n\times n$ 矩阵，由 $A$ 的元素决定，但不含 $\lambda$。

把这个展开式代回 $(\ast)$ 式左边：

$$(\lambda I-A)\sum_{k=0}^{n-1}\lambda^k C_k=\sum_{k=0}^{n-1}\lambda^{k+1}C_k-\sum_{k=0}^{n-1}\lambda^k AC_k=\sum_{k=1}^{n}\lambda^k C_{k-1}-\sum_{k=0}^{n-1}\lambda^k AC_k$$

按 $\lambda^k$ 的次数整理系数：$k=0$ 对应 $-AC_0$；$k=1,\dots,n-1$ 对应 $C_{k-1}-AC_k$；$k=n$ 对应 $C_{n-1}$。右边则是 $P(\lambda)I=\sum_{k=0}^n a_k\lambda^k I$（记 $a_n=1$）。

一旦想到这一层，整个证明的骨架就基本定型了：两个矩阵系数多项式相等，当且仅当逐次幂系数相等——这跟普通标量多项式的比较系数法是完全平行的操作，只是把标量换成了矩阵（矩阵乘法虽不交换，但这里 $A$ 和这些 $C_k$ 之间的运算顺序是被恒等式本身固定好的，不会引发麻烦）。由于 $(\ast)$ 式对**所有** $\lambda$ 都成立，两边 $\lambda$ 同次幂前的矩阵系数必须逐一相等，于是得到一串矩阵方程：

$$
\begin{aligned}
k=0:&\quad -AC_0 = a_0 I\\
k=1:&\quad C_0-AC_1 = a_1 I\\
k=2:&\quad C_1-AC_2 = a_2 I\\
&\ \ \vdots\\
k=n-1:&\quad C_{n-2}-AC_{n-1} = a_{n-1} I\\
k=n:&\quad C_{n-1} = I
\end{aligned}
$$

这些方程各自都不是我们要的结论，孤立看没什么用。但注意到，如果在第 $k$ 个方程两边左乘 $A^k$，会得到 $A^kC_{k-1}-A^{k+1}C_k = a_kA^k$，这样一来，前一个方程里出现的 $A^{k}C_{k-1}$，恰好会和下一个方程构造出的 $A^{k}C_{k-1}$ 严格重合（只差一个符号）。这个"错位相消"的设计并非凭空而来，而是**目标倒推**出来的：我们想要的最终等式右边是 $\sum a_k A^k$，也就是每一层方程右边 $a_k I$ 恰好需要被乘上 $A^k$ 才能拼出目标；既然目标决定了每层要乘 $A^k$，那么左边自动就会因为 $C_k$ 前后相邻两层符号相反、次数差一，而呈现出错位相消的形式——这更像是"知道要去哪儿"之后自然浮现的构造，而不是灵光一现的巧合。

把第 $k$ 条等式两边同时左乘 $A^k$：

$$
\begin{aligned}
k=0:&\quad -AC_0 = a_0 I\\
k=1:&\quad A C_0-A^2C_1 = a_1 A\\
k=2:&\quad A^2C_1-A^3C_2 = a_2 A^2\\
&\ \ \vdots\\
k=n-1:&\quad A^{n-1}C_{n-2}-A^{n}C_{n-1} = a_{n-1} A^{n-1}\\
k=n:&\quad A^{n}C_{n-1} = A^n
\end{aligned}
$$

接下来是整个证明里最巧妙的一步：把所有层的等式**加总**起来。左边求和：

$$-AC_0+(AC_0-A^2C_1)+(A^2C_1-A^3C_2)+\dots+(A^{n-1}C_{n-2}-A^nC_{n-1})+A^nC_{n-1}$$

你会发现，几乎每一项都以 $A^kC_{k-1}$ 这样的形式出现两次、符号相反，像拉手风琴一样一层一层地连锁抵消：$-AC_0$ 与 $+AC_0$ 抵消，$-A^2C_1$ 与 $+A^2C_1$ 抵消……一直到 $-A^nC_{n-1}$ 与最后一条的 $+A^nC_{n-1}$ 抵消。所有 $C_k$ 项两两相消，左边最终整体抵消为零矩阵：

$$O\ (\text{零矩阵})$$

而右边因为每一层原本就是 $P(\lambda)$ 按 $\lambda^k$ 展开后对应的系数乘上 $A^k$，加总起来恰好精确地拼出

$$a_0I+a_1A+a_2A^2+\dots+a_{n-1}A^{n-1}+A^n=P(A)$$

于是两边相等：

$$O=P(A)=A^n+a_{n-1}A^{n-1}+\dots+a_1A+a_0I$$

证毕。

整个推导中唯一用到的性质是：其一，$M\cdot\mathrm{adj}(M)=\det(M)I$ 对**任意**方阵恒成立，是伴随矩阵的定义性质；其二，$\mathrm{adj}(\lambda I-A)$ 的每个元素是 $\lambda$ 的多项式、次数 $\le n-1$，这只是"子式是元素乘积之和"的组合事实，与 $A$ 的特征结构（是否有重根、是否可对角化）完全无关。整个证明没有出现"设 $v$ 是特征向量""设 $A=PDP^{-1}$"这类只对可对角化矩阵有效的操作，比较的只是矩阵系数多项式的恒等式，所以对所有方阵——包括有若尔当块、亏损特征向量的病态矩阵——都成立。这也解释了第二节几何证明留下的漏洞：可对角化证明本质上只是这个一般证明在 $A$ 恰好可对角化这一特殊情形下的简化版本。

这个证明的本质在于：特征多项式和伴随矩阵其实是同一个行列式恒等式 $M\cdot\mathrm{adj}(M) = \det(M)I$ 在不同维度上的两种呈现，凯莱-哈密顿定理只是把这层内嵌的代数结构，用矩阵幂次的加权求和"翻译"了出来。它完全不依赖对角化，因此对任意方阵普遍成立，这也是为什么教材更偏爱这个证明而不是几何证明。

若回头看整条思路是怎么被想出来的，会发现它其实遵循了一个很常见的数学思维模式——遇到"不能直接做的操作"（把矩阵代入标量多项式），就去找一个"结构上等价、但形式上允许这样做"的恒等式（伴随矩阵公式），然后利用这个恒等式两边天然共享的代数结构（都是关于 $\lambda$ 的矩阵系数多项式），把问题转化成一个可以逐层对比、机械操作的形式（比较系数 + 加权求和消元）。换句话说，凯莱-哈密顿定理在这个视角下，甚至算不上一个需要"洞察"矩阵几何意义的定理，而更像是伴随矩阵恒等式在多项式语言下的一个自动推论。

## 四、这个定理到底有什么用

凯莱-哈密顿定理并不只是一个数学上好看的对称性，它在实际计算里能带来实打实的化简。

**降阶高次矩阵幂。** 如果要算 $A^{100}$，硬乘 99 次代价很高。但既然 $P(A) = O$，$A^n$ 就可以用 $A$ 的更低次幂表示出来（把 $A^n = -(a_{n-1}A^{n-1}+\dots+a_0I)$ 移项即得）。于是可以做多项式的带余除法：用 $P(x)$ 去除 $x^{100}$，得到商式和一个次数不超过 $n-1$ 的余式 $R(x)$，即 $x^{100} = Q(x)P(x) + R(x)$。把 $x$ 换成 $A$，由于 $P(A) = O$，右边第一项直接消失，只剩下 $A^{100} = R(A)$。这样就把一个 100 次幂的计算，缩减成了只需要知道 $I, A, A^2, \dots, A^{n-1}$ 这 $n$ 项系数组合，计算量和矩阵阶数无关，只取决于 $n$。

**求逆矩阵，完全绕开伴随矩阵法。** 设 $P(\lambda) = \lambda^n + a_{n-1}\lambda^{n-1} + \dots + a_1\lambda + a_0$，只要 $a_0 \ne 0$（这等价于 $A$ 可逆，因为 $a_0 = (-1)^n\det(A)$），由 $P(A) = O$ 展开：

$$A^n + a_{n-1}A^{n-1} + \dots + a_1A + a_0I = O$$

把常数项之外的所有项挪到一边，再提出一个公因子 $A$：

$$A\left(A^{n-1} + a_{n-1}A^{n-2} + \dots + a_1I\right) = -a_0I$$

两边同除 $-a_0$，就直接读出了逆矩阵的显式表达式：

$$A^{-1} = -\frac{1}{a_0}\left(A^{n-1} + a_{n-1}A^{n-2} + \dots + a_1I\right)$$

这意味着求逆矩阵根本不需要走"求所有代数余子式、拼伴随矩阵、再除以行列式"这条又长又容易算错的路，只要知道特征多项式的系数，逆矩阵就是 $A$ 的一个具体多项式组合，直接算出来。

**矩阵指数的有限化，这是控制理论和微分方程里最重要的应用之一。** 常系数线性微分方程组 $\dot{x} = Ax$ 的解由矩阵指数 $e^{At} = \sum_{k=0}^{\infty}\frac{t^k}{k!}A^k$ 给出，这本身是一个无穷级数，直接算无从下手。但凯莱-哈密顿定理保证了 $A^n$ 以及之后所有更高的幂次，都能用 $I, A, \dots, A^{n-1}$ 的线性组合表示出来——所以整个无穷级数里，凡是次数达到 $n$ 或以上的项，都可以逐一"折叠"回前 $n-1$ 项里去，累加出一组新的、依赖 $t$ 的系数函数 $\alpha_0(t), \alpha_1(t), \dots, \alpha_{n-1}(t)$，使得

$$e^{At} = \alpha_{n-1}(t)A^{n-1} + \dots + \alpha_1(t)A + \alpha_0(t)I$$

这样一来，原本无穷维的计算问题，就被压缩成了只需求出 $n$ 个标量函数 $\alpha_i(t)$（通常通过特征值代入 $P(\lambda)$ 的思路反解出来），再配上矩阵的前 $n-1$ 次幂就能拼出精确解。这正是现代控制理论里状态转移矩阵能够被有效计算的根本原因。

---

这三节合起来讲的其实是同一件事的三重身份：**代数上**，它保证了某组特定系数（不多不少刚好是特征多项式系数）能让矩阵的幂级数归零；**几何上**，这组系数之所以有效，是因为特征多项式的每个因子恰好瞄准并抹平了一个特征方向；**结构上**，即便没有特征向量可用，行列式与伴随矩阵之间的恒等式依然能不依赖对角化地把这件事重新证明一遍。而它的价值正来自于这种"归零"性质——只要矩阵能让自己的特征多项式归零，无穷次幂、逆矩阵、矩阵指数，这些原本看似需要无限信息的对象，就都能被压缩进前 $n-1$ 次幂张成的有限空间里。
