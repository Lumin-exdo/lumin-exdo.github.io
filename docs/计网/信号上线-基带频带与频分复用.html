信号怎样放上线：基带传输、频带传输、频分复用

同样发 1010：网线放方波；电话线先调制到载波；电视线几路各占一段频率。

三种放上线的办法，各是什么

基带 ／ 频带 ／ 频分复用
名称做法线上是什么典型场合书上的叫法
基带传输基带信号是信源发出的、没经过调制的原始电信号，直接放上线：1 高电平，0 低电平直接的电压（方波），占整条带宽，从 0 Hz 起短距离：局域网、计算机内部。常用编码见 2.1b基带传输
频带传输先调制：把基带信号搭载到一个高频载波上，整体搬到信道能通过的那一段一路载波（图中 1800 Hz，幅度大 1、小 0）远距离、无线：拨号上网、Wi-Fi。调制方式见 2.1b宽带传输（调制后的信号叫宽带信号）
频分复用把线能通过的频率范围分成几段，每段上各做一路频带传输三路载波，各占一段频率有线电视线：看电视的同时上网书中无；另一些教材也叫“宽带传输”（书外补充）

王道教材（2027 版）说的“宽带传输”就是第二行：把基带信号调制到高频载波上形成宽带信号，用它传输叫宽带传输，也叫频带传输。第三行是另一些教材（传统语境）里“宽带传输”的意思，书里没有这个含义。

同一个名字“宽带传输”，指两件事

第二行 与 第三行 的关系
  1. 第二行（频带传输）：一路信号，靠一个载波上线。宽带信号＝调制到载波上的信号。
  2. 第三行（频分复用）：同一条线上同时放几路，每路各自是第二行那样的一路频带传输，只是载波频率互不相同。
  3. 所以第三行是建在第二行之上的：没有“把信号搬到载波上”，就没法把几路并排放进不同的频率段。区别是路数：一路对多路。

读到“宽带传输”时，看上下文：讲调制、载波、基带信号的，指第二行；讲一条线分成多个信道、多路并行的，指第三行。本节用频带传输、频分复用两个不会混的名字。

电话线为什么不能直接发方波

0～300 Hz 被挡掉
  1. 电话线只让 300～3300 Hz 的信号通过（图中右边的蓝条）。
  2. 方波里有很低的频率成分：连发 1111…，线上是一段保持不变的 3 V，不变的电压就是 0 Hz；1010 的方波也含有从 0 Hz 起的一大片频率（虚线框，右端敞开）。
  3. 0～300 Hz 被挡掉（红色），波形就坏了。所以要先调制，把信号搬进 300～3300 Hz。B 看每一格里载波幅度的大小，还原出 1010。

信道的两种分类，图中各标在哪

数字／模拟，有线／无线

按信道上传的信号形式分：数字信道（网线直接放高低电平）、模拟信道（电话线、有线电视线上放连续起伏的波）。按传输介质分：有线信道、无线信道。两种分类互相独立：本图三行都是有线信道，一行数字、两行模拟；Wi-Fi 是无线的模拟信道，用频带传输。
